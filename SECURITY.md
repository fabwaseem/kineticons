# Security

## Supported versions

Security fixes go into the latest published version of each package.

## Reporting a problem

Please do not open a public issue for a security problem. Report it privately through
[GitHub's security advisories](https://github.com/fabwaseem/kineticons/security/advisories/new). Say what is affected,
how to reproduce it, and its impact. You will hear back within a few days, and once a fix is out you will be credited
unless you prefer otherwise.
