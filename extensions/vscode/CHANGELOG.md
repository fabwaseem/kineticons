# Changelog

## 0.1.0

First release.

- **Kineticons: Insert icon**: search 2,083 icons with previews, pick outline, duotone or filled, and insert a React,
  Vue or Svelte component with its import, or the raw SVG in any other file.
- **Kineticons: Copy SVG**: copy an icon's SVG, motion included, to the clipboard.
- **Kineticons: Open in browser**: open an icon's page on kineticons.fabwaseem.com.
- Icons from `@kineticons/static` 0.1.0, bundled for offline use.
